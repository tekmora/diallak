# Security Policy

## Supported Versions

Only the latest release and current default branch receive security updates.

## Reporting a Vulnerability

Please report a security vulnerability privately, not in a public issue or
discussion. Use the private reporting form of this repository:
<https://github.com/tekmora/discord-bot/security/advisories/new>
(tab "Security", button "Report a vulnerability").

Reports are investigated promptly under responsible disclosure guidelines.
