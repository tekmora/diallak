# Server rules

Draft. It is not published to members yet. The operator has accepted the eight
rules as draft wording. The organisation's
[code of conduct](https://github.com/tekmora/.github/blob/main/CODE_OF_CONDUCT.md) now
exists; its section "Our Pledge" is proposed wording that the operator has not
accepted yet. The rules become final when the operator accepts them together
with the code of conduct.

The operator decided the shape: one code of conduct holds the rules of conduct
for all spaces of the organisation, and the server rules are a short add-on for
what is specific to the server. A member reads them when joining.

English is the source and the binding version of these rules. A translation is
linked when someone provides it and is marked as a translation.

## The rules

1. **The code of conduct applies here.** The
   [code of conduct](https://github.com/tekmora/.github/blob/main/CODE_OF_CONDUCT.md) says
   how people treat each other in every space of the organisation, and how to
   report a breach of it.
2. **Technical channels and support are in English.** A language gets a social
   room when enough members ask for it and a moderator or subject guide who
   reads the language watches the room. There is none at the start.
3. **Ask for help in the support forum, one post per question.** Others then
   find the answer. A post may carry a language tag; an answer points to the
   English thread when one exists. A sensitive case does not go into the
   forum: open a private thread in the ticket channel.
4. **Keep to the topic of a channel.**
5. **The assistant is automated.** Its replies say so and can be wrong: check
   the sources it cites. In the support forum it reads the first message of a
   new post and may reply first, when the post carries the tag "Automated
   answer". Do not put secrets or personal data into a question.
   What it does with a question is in the [privacy notice](privacy-notice.md).
6. **Report security problems privately**, as [SECURITY.md](../../SECURITY.md)
   describes, not in a public channel.
7. **Moderators may remove content and time members out.** People decide every
   unclear case, never the bot alone. Moderators follow the
   [moderator guide](../moderator-guide.md), and every act is recorded with
   its reason. To object to an act, write to the e-mail address in the
   [imprint](imprint.md): that is the binding path, and it works when you can
   no longer reach the server. A private thread in the ticket channel,
   addressed to the operator, is accepted too. Moderators who manage threads
   can see such a thread. The operator decides the objection.
8. **Discord's own rules apply.** You must follow Discord's Terms of Service
   and Community Guidelines and meet Discord's minimum age for your country.
   The server has no mature content and no age-restricted channel.

## What the code of conduct covers

The code of conduct is written once per organisation. Until it existed, a list
of rules of conduct stood in for it in this draft. The code of conduct now
covers these points of that list:

- Respect: no harassment, no hate speech, no threats.
- Other people's privacy: no personal information about anyone without their
  consent.
- No sexual content.
- No impersonation of another person, a moderator or a project.
- No advertising.

These points of the list are not in the code of conduct, so they stay with
the server and hold here in addition to it:

- No gory or shocking content.
- No spam: no unsolicited invitations, no repeated posts.
- No scams: no phishing, no malware, no solicitation of money.
- Respect for licences: no pirated software and no help with getting it.
- Nothing illegal.

## How the rules are applied

[ADR-0005](../adr/0005-moderation-and-escalation.md) fixes the order: the
platform's own moderation rules filter spam and obvious abuse, moderators decide
every unclear case, and the operator is the last instance. The bot assigns no
role and punishes nobody on its own judgement.

Rule 5 rests on the [AI disclosure](ai-disclosure.md) and on
[ADR-0002](../adr/0002-data-and-compliance.md).

## Where these rules live

The source is this file in the project's repository. Once published, the rules
are shown in the server's rules screen and linked from the rules channel. They
link the [imprint](imprint.md) and the [privacy notice](privacy-notice.md). They
move when the organisation has one place for its legal texts, and a link stays
behind.

Where the code of conduct lives is recorded in
[ADR-0008](../adr/0008-code-of-conduct-place.md): once per organisation, not in
this repository.

## Open points

- The operator accepts or changes the section "Our Pledge" of the code of
  conduct, which is proposed wording.
- The points that stay with the server, listed above, are not yet in the
  rules a member reads: the operator decides whether they become a rule of
  their own here or move into the code of conduct.
